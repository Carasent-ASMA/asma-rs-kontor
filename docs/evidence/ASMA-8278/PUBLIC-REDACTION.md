# Public evidence derivative

Decision: LSA-WP01-PUBLIC-EVIDENCE-001.

Files listed in [PUBLIC-REDACTION.json](PUBLIC-REDACTION.json) are public redacted derivatives. Private repository identifiers, operator-identifying paths and private workspace paths were replaced with bracketed placeholders. The ledger records each original and derivative SHA-256. The original bytes are retained in the access-controlled evidence store; the TPM owns the exact-path disposition ledger.
